# Phase 14 Handoff — Editor Core & Interaction Engine

> Phase 14.1 hardening supersedes this handoff for current ownership and
> residual-risk details. Read [`phase-14.1-handoff.md`](phase-14.1-handoff.md)
> before continuing editor work.

## Current truth

The Builder uses Model A. GrapesJS owns the live component model and its
`UndoManager`; `PagePayload` is the only persisted content contract; validation
precedes immutable PageVersion save; the public renderer is production authority.
Do not introduce a second normalized editable document store.

## Command and placement boundaries

- `apps/cms/builder/editor-commands.ts` exports `EditorCommand`,
  `executeEditorCommand`, and `createEditorCommandBus`.
- All structural movement uses `MoveNodeIntent` (`before`, `inside`, `after`) and
  `builder-placement.ts`. This is shared by Canvas, Layers, selected move buttons,
  and Quick Add insertion decisions.
- Same-parent placement passes a deterministic destination index to GrapesJS,
  whose collection move semantics account for source removal. Ancestor-to-
  descendant, root, missing-node, and registry-invalid moves are rejected before
  mutation.
- Stable IDs are `data-payload-node-id`; duplicate subtree IDs are regenerated by
  the existing `reassignEditorNodeIds` clone hook.

## Selection and synchronization

`BuilderSelection` stores only `selectedNodeId` for the session and resolves a
current GrapesJS component when needed. Canvas selection, Layers, Inspector,
breadcrumb, minimap, and context toolbar are fed by the same selection callback.
Delete and history commands return a surviving parent/root selection so dangling
component references are not retained.

## Interaction UX

`builder-context-toolbar.tsx` and `quick-add-overlay.tsx` are presentational
surfaces. They call the `GrapesEditorHandle` command methods. Layers and Canvas
show `before`/`inside`/`after`; invalid Layer drops have an accessible status and
invalid Canvas drops retain a red indicator/title. Escape cancels temporary drag
state. Keyboard shortcuts are ignored while typing.

## Save and renderer invariants

The existing manual immutable version endpoint, optimistic conflict handling,
preview `postMessage` bridge, responsive breakpoint registry, and renderer mapping
were intentionally not redesigned. New mutations must continue to serialize with
`serializeGrapesComponent` and pass `PagePayloadSchema` before save or preview.

components. Add a registry definition, adapter mapping, renderer mapping, and
round-trip/placement coverage together. Keep command ownership authoritative and
avoid mutating GrapesJS from new panels directly.
