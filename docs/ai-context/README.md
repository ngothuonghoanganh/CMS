# Payload Page Platform — AI Context Pack

This folder contains a repository-ready documentation pack for the `ngothuonghoanganh/CMS` project.

## Install into repository

Copy:

- `AI_CONTEXT.md` → repository root
- `docs/ai-context/` → repository `docs/ai-context/`

The root `AI_CONTEXT.md` is intentionally the entry point for future AI agents.

## Contents

- Product/domain context
- Current problem map
- Target architecture
- Editor Core / PageDocument model
- Builder UX specification
- CMS UX / design-system specification
- Multi-tenancy/security rules
- Testing quality gates
- Recovery roadmap
- AI coding/working protocol

These documents intentionally distinguish **target architecture** from **verified source implementation**. A future agent must still audit the actual repository before changing architecture.
